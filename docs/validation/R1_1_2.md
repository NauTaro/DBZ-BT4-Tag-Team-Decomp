# BT4decomp 0.1.39.6 R1 1.2

Candidate prepared on 2026-11-16. Canonical updater identity: `0.1.39.6-R1.3`.
This preparation does not deploy the online service or reset Ranked.

## Repairs and evidence

- Tag effects: the exact shipped executable maps crash `+0x115a3b` to
  `EftCharaFx_Stop`. Five per-character tables contained two entries for a
  ten-actor mode. PC tables now have ten independent entries and guarded access.
  Console layouts are retained. Native tests exercise all five tables, ten
  actors, invalid IDs, missing work and a memory canary.
- Simultaneous draft: crash `+0x2da6d4` reaches `freeze_block` from the selector
  texture queue. Unconfirmed character `-1` selected archive header entry zero.
  Empty draft seats now retain a null texture. All 32 confirmation masks on both
  teams are tested with the production texture routine.
- Ginyu: negative animation/data/voice IDs caused Body Change to request a
  model-only reload. Both bodies now request full character reloads. Production
  queue tests cover saturation, asynchronous loading, non-adjacent seats and
  preservation of HP and controller ownership. Actual executable probes finish
  Body Change with actors 0/1 and 9/2 in duel and ten-actor scenes.
- Potaras: native online rules explicitly distinguish competitive queues from
  private rooms. Quick Match and Ranked retain mechanical restrictions; private
  duels/tournaments and Tag custom rules allow their selected items. Beginning a
  private/address room clears a previous queue's flag. Production item tests
  cover all 350 entries, stacking and authoritative item sets for ten actors.
- Tournament: first-round vacant leaves are labeled as byes, while unplayed
  qualifiers remain pending. Actual bracket and page routines are tested for
  every entrant count 2..22, both winners, one appearance per entrant and n-1
  played matches. Offline bracket page 21 uses one coordinate anchor for its
  tree and portraits; the native anchor test covers that page.
- Camera video: camera-relative streak fields now check their owner before
  drawing. Explicit world-position effects remain visible to everyone. Native
  full-draw tests exercise ten owners against ten viewers. Hidden Vulkan runs
  render the attack participant and an outsider and both return to combat.
  The exact complete sequence in the supplied phone video was not reproduced;
  unrelated global stage lighting was not changed without evidence.
- Saved Tag camera: the owner's A/B/C distance is carried in reserved input byte
  10 and read from delivered history, keeping the native camera path identical
  between peers. Ally/free focus modes remain unchanged. Native tests cover ten
  actors, each distance, receiver-independent preferences and invalid bytes.
- Voices: partner events use the BT4 voice base. Online alternate streams and
  banks use BT4's 250-character ranges while retaining BT3 fallback. Tests cover
  all 25,000 stream IDs, both bank sets and boundaries. Read-only archive probes
  inspect 36 installed ADX files and six banks; production routing probes compare
  the replacement bank headers, sequences and ADPCM sample bytes. No subjective
  listening assessment is claimed.
- Generic USB pads: an instance-local SDL mapping admits unmapped standard
  four-axis, 12..16-button, one-hat controllers. Known SDL mappings and wheel /
  flight devices are left alone. Actual SDL virtual-joystick tests cover buttons,
  triggers, both sticks and D-pad. The reported physical EG102 was unavailable.
- Settings: duplicate numeric keys are normalized with the last value retained,
  and numeric capacity is increased from 250 to 4096. The production persistence
  test changes main-menu music after 400 settings and reloads it in a new process.
  The reporter's exact music-selection failure was not reproduced with a normal
  configuration; the current menu already saves and reads the selected track.
- PR #64: merged as `7cca8337a63b395367e084c5605897a23b259280`, after schema,
  Windows/Linux/macOS package fixtures and successful repository checks on Windows
  and Ubuntu. Upstream contributor attribution is preserved.

## Additional verification and limits

The native public build links successfully. Regression tests also cover public
battle input, camera pose/pause/full-screen projection, effect loading, sequence
commands, FFA and native/WASM transport parity over eight 2,000-frame scenarios.
The actual executable passes a ten-actor camera audit with 191 checks, target
audit, battle finish/result and both Ginyu probes.

The reported Time Chamber Smooth Motion flicker (#53) did not appear in the
current deterministic hidden-render run. Real and interpolated images were
captured in that stage, including turns, attacks and teleports. This does not
close every renderer/driver case. The custom-camera issue (#60) has passing
existing projection/pause/resimulation regressions but still needs the affected
player's long online session. Neither issue is represented as universally fixed.

Official Windows Authenticode signing (#51) still depends on the production
SignPath certificate/token. Existing integration is retained. A ZIP checksum or
updater signature is not an Authenticode certificate.

The approved #61 HUD remains unchanged. Suggestions were excluded. No foreground
desktop automation, firewall change, live-service deployment or additional
Ranked reset is part of this preparation. Internet conditions and all hardware /
roster combinations have not been exhaustively tested. All participants must use
the new candidate and create a fresh room because simulation compatibility is
now `BT4-B14-Rev2-sim7`.
